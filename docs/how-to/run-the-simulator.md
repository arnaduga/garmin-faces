# Run the simulator

1. Start the container with `scripts/shell.sh` (it publishes port 6080).
2. Run `scripts/simulate.sh src/<face-name>`.
3. Open <http://localhost:6080/vnc.html> in your browser and click **Connect**.
4. The simulator window shows your face. Rebuild and rerun the script after each change.

Press `Ctrl+C` in the container to stop everything.
